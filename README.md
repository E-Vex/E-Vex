I'm a first-year computer science student at CNAM Lebanon. I build systems software in C and Rust, mostly from scratch: a packet analyzer, a terminal editor, a deterministic strategy-game simulation, and the small tools I use every day. My focus is moving toward cybersecurity, with AI further out.

## Featured

### [Pandemonium: Build & Destroy](https://github.com/E-Vex/pandemonium-bd)

A deterministic real-time strategy foundation written from scratch in Rust, with no game engine and no ECS framework. A match is a seed, a content hash and an ordered command log, and replaying those on any machine has to reproduce every tick checksum. Nine crates, fixed-point math, no floats in the simulation. Presentation assets live in [pandemonium-assets](https://github.com/E-Vex/pandemonium-assets).
